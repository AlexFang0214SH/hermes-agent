- **入口与传输层**：`entry.py` 负责 CLI 启动、环境变量加载及日志配置（强制 stderr 输出以保留 stdout 给 JSON-RPC），通过 `acp.run_agent` 启动 stdio 传输。
- **核心代理层**：`server.py` 实现 `HermesACPAgent`，处理 ACP 生命周期（初始化、认证、会话创建/恢复/分叉），并将 ACP 请求映射到内部 `AIAgent`。
- **会话与状态层**：`session.py` 管理 `SessionState`，通过 `SessionDB` 持久化会话历史，支持跨进程恢复；`provenance.py` 提供会话血缘元数据。
- **工具与事件桥接**：`tools.py` 定义工具类型映射及结果格式化；`events.py` 将 Agent 内部事件（思考、工具进度）转换为 ACP 流式更新。
- **安全与权限层**：`permissions.py` 和 `edit_approval.py` 处理危险命令审批及文件编辑预检，通过 `ContextVar` 隔离不同平台的审批逻辑。

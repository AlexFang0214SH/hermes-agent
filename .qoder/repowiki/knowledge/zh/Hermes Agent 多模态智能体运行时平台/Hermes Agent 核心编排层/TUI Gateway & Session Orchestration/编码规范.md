- 采用装饰器 `@method("name")` 在 `server.py` 中注册 JSON-RPC 处理函数，实现方法名到 callable 的自动映射。
- 所有耗时或阻塞的 RPC 处理器（如 `slash.exec`, `session.resume`）被标记为 `_LONG_HANDLERS`，自动卸载到线程池执行以避免阻塞主事件循环。
- 会话状态变更（创建、关闭、回收）统一通过 `_sessions_lock` (RLock) 保护，并遵循“先弹出后清理”的模式以防止竞态条件。
- 传输层写入操作（`write_json`）优先从当前 `contextvars` 获取绑定的 Transport，若不存在则回退到模块级的 StdioTransport，确保多线程环境下输出路径的正确性。

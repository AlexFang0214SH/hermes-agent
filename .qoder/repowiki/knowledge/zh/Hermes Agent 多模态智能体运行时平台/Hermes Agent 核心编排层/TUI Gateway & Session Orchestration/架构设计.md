- **入口与循环**：`entry.py` 作为独立进程入口，通过 `sys.stdin` 读取 JSON-RPC 请求并调用 `dispatch` 路由。
- **核心逻辑层**：`server.py` 包含庞大的 RPC 方法注册表（如 `session.create`, `prompt.submit`），维护全局 `_sessions` 状态字典，并实现延迟代理构建（Deferred Build）以优化启动性能。
- **传输抽象层**：`transport.py` 定义 `Transport` 协议，利用 `contextvars` 实现请求级传输绑定；`ws.py` 提供基于 FastAPI/Starlette 的 WebSocket 适配，支持跨线程安全写入。
- **隔离执行层**：`slash_worker.py` 作为独立的子进程，通过 stdin/stdout 管道持久化运行 `HermesCLI`，隔离斜杠命令的执行环境。
- **依赖方向**：入口层依赖核心逻辑层，核心逻辑层通过适配器模式依赖传输层，所有组件共享全局会话状态锁。

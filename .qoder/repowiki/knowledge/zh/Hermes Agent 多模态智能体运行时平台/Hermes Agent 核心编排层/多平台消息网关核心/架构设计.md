- **动态适配器注册**：采用 `PlatformRegistry` 模式解耦核心逻辑与具体平台实现，支持内置及插件化适配器的自动发现与实例化。
- **标准化通信契约**：定义 `BasePlatformAdapter` 抽象基类，强制所有子模块遵循统一的 `connect`、`send` 及 `handle_message` 接口规范。
- **流式消费桥接**：利用 `GatewayStreamConsumer` 将同步的 Agent 输出流转换为异步的平台渐进式编辑（Edit）或原生草稿（Draft）更新。
- **中继扩展架构**：通过 `relay/` 模块提供基于 WebSocket 的通用传输层，允许外部连接器通过能力协商（Capability Negotiation）动态扩展网关边界。

- 所有浏览器工具函数均接受 `task_id` 参数以实现多任务会话隔离，并在内部通过线程锁（如 `_sessions_lock` 或 `_state_lock`）保护共享状态。
- 工具返回结果统一序列化为 JSON 字符串，成功时包含 `success: true` 及业务数据，失败时包含 `success: false` 及 `error` 描述。
- 采用懒加载与缓存机制（如 `_get_cloud_provider`、`_get_command_timeout`）解析配置与环境变量，避免在每次工具调用时重复读取文件系统。
- 在涉及 CDP 通信的模块中，实现了从同步调用到异步事件循环的安全桥接模式，确保在非异步上下文中也能稳定执行 WebSocket 操作。

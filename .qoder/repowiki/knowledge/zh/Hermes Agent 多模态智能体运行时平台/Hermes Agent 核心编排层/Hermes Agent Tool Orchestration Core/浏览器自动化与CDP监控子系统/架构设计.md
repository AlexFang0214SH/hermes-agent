- **核心控制层**：`browser_tool.py` 作为统一入口，通过 `_get_cloud_provider` 和 `_is_camofox_mode` 动态路由至 Browserbase/Browser Use 云端服务、本地 `agent-browser` CLI 或 Camofox REST API。
- **CDP 监控层**：`browser_supervisor.py` 维护持久化 WebSocket 连接，订阅 Page/Runtime/Target 事件以捕获原生对话框（alert/confirm/prompt）和跨域 iframe (OOPIF) 结构，支持自动策略处理。
- **CDP 交互层**：`browser_cdp_tool.py` 提供原始 CDP 命令透传能力，支持通过 `target_id` 或 `frame_id` 精确控制特定标签页或 iframe 上下文。
- **对话框响应层**：`browser_dialog_tool.py` 封装对 Supervisor 捕获的待处理对话框的响应逻辑（accept/dismiss）。
- **反检测后端**：`browser_camofox.py` 实现基于 Camoufox 的 REST 接口适配，支持指纹伪装、VNC 可视化及会话持久化管理。

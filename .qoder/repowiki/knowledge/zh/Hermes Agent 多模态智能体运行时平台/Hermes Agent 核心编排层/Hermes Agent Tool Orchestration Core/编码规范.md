- Tools self-register via `registry.register()` at module import time, ensuring automatic discovery without manual enumeration in the orchestrator.
- All tool handlers must return JSON-serialized strings, utilizing `registry.tool_result()` and `registry.tool_error()` helpers for consistent formatting.
- Availability checks (`check_fn`) are TTL-cached (30s) to amortize expensive external state probes (e.g., Docker daemon, binary existence) across rapid schema re-evaluations.

- **核心运行时 (`mcp_tool.py`)**: 采用后台守护线程运行专用asyncio事件循环 (`_mcp_loop`) 的架构。每个MCP服务器由 `MCPServerTask` 管理，在独立任务中维持长连接，支持自动重连、指数退避及保活机制。工具调用通过 `run_coroutine_threadsafe` 跨线程调度。
- **OAuth认证层 (`mcp_oauth.py`, `mcp_oauth_manager.py`)**: `HermesTokenStorage` 负责令牌与客户端信息的持久化（含磁盘mtime监控以检测外部刷新）。`MCPOAuthManager` 作为单例管理中心，提供401错误去重处理及跨进程状态同步，构建 `HermesMCPOAuthProvider` 子类以增强SDK默认的元数据发现与令牌重载逻辑。
- **注册与适配**: 通过 `_register_server_tools` 将MCP工具映射到内部注册表，包含JSON Schema标准化 (`_normalize_mcp_input_schema`)、提示注入扫描及并行执行安全标记。支持动态工具更新监听 (`notifications/tools/list_changed`)。

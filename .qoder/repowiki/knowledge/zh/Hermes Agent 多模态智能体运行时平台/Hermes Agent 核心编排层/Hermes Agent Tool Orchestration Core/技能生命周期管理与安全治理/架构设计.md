- **核心工具层**：`skills_tool.py` 实现 `skills_list`（元数据列表）和 `skill_view`（内容加载），支持本地文件系统与插件命名空间（`namespace:skill`）的混合解析。
- **管理操作层**：`skill_manager_tool.py` 暴露 `skill_manage` 工具，处理技能的 CRUD 操作，通过原子写入（`atomic_replace`）保证数据一致性，并集成写前审批门控（Write Approval Gate）。
- **安全审计层**：`skills_guard.py` 提供静态分析扫描器，检测提示注入、秘密泄露等威胁模式；根据来源（内置/可信/社区）应用不同的安装策略。`skills_ast_audit.py` 提供可选的 Python AST 深度审计。
- **状态与同步层**：`skill_usage.py` 维护 `.usage.json` 侧车文件以跟踪使用频率和生命周期状态（活跃/陈旧/归档）；`skills_sync.py` 负责从捆绑包同步技能并维护 `.bundled_manifest`；`skills_hub.py` 处理来自 GitHub 等远程源的拉取与隔离区（Quarantine）管理。
- **依赖方向**：所有工具模块均依赖于 `hermes_constants` 获取路径配置，并通过 `agent.skill_utils` 共享解析逻辑，形成以 `~/.hermes/skills` 为单一事实来源的架构。

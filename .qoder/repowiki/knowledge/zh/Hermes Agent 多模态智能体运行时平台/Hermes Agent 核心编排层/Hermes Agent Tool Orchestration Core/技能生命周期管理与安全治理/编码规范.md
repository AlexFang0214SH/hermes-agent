- 所有技能文档（SKILL.md）必须采用 YAML Frontmatter 格式，包含必填的 `name` 和 `description` 字段，且遵循 agentskills.io 兼容标准。
- 文件写入操作（如创建或更新技能）必须使用临时文件配合 `os.replace` 或 `atomic_replace` 进行原子写入，防止进程中断导致的数据损坏。
- 在处理技能名称或文件路径时，必须执行严格的路径安全检查，禁止绝对路径、Windows 驱动器路径及包含 `..` 的遍历组件，以防止目录逃逸。
- 技能加载与列表展示实施渐进式披露（Progressive Disclosure）策略：列表仅返回元数据，完整内容及关联文件需通过显式的 `skill_view` 调用按需加载。

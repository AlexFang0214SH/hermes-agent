- **核心调度层**：`scheduler.py` 实现 `tick()` 机制，通过文件锁防止并发执行，利用线程池并行处理耗时任务，并集成 `AIAgent` 执行自包含提示词。
- **持久化存储层**：`jobs.py` 管理 `~/.hermes/cron/jobs.json`，提供原子读写、跨进程锁及 CRUD 接口，支持 cron/interval/once 多种调度模式。
- **自动化生态层**：`blueprint_catalog.py` 定义参数化模板（Blueprints），`suggestions.py` 管理待确认的自动化建议（Suggestions），实现从“推荐”到“创建任务”的闭环。
- **交付与扩展**：内置多平台（Telegram, Slack 等）交付逻辑，支持通过 `scripts/` 目录下的 Python/Bash 脚本进行无代理（no_agent）数据收集或监控。

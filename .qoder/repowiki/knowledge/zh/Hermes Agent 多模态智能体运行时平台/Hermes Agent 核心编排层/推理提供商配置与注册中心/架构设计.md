- **核心抽象层**：`base.py` 定义了 `ProviderProfile` 数据类，采用声明式设计封装身份、端点、鉴权类型（如 `api_key`、`oauth`）及请求级特性（如 `fixed_temperature`、`default_headers`），并通过钩子方法（如 `prepare_messages`、`build_extra_body`）实现特定逻辑扩展。
- **注册与发现层**：`__init__.py` 维护全局注册表 `_REGISTRY`，实现懒加载机制。首次访问时按优先级扫描并导入三类来源：仓库内置插件（`plugins/model-providers/`）、用户自定义插件（`$HERMES_HOME/plugins/`）以及兼容旧版的单文件模块。
- **接口边界**：对外暴露 `get_provider_profile` 和 `list_providers` 接口，供 `hermes_cli/auth.py`、`agent/transports/` 等下游模块读取配置以动态构建 API 请求或执行健康检查，实现了配置定义与业务逻辑的解耦。

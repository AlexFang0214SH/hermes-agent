- **入口层**：`main.py` 作为主入口，负责早期环境初始化（UTF-8 修复、Termux 优化）、Profile 覆盖逻辑及 `.env` 加载。
- **解析层**：`_parser.py` 定义顶层 `argparse` 结构；`subcommands/` 目录通过 `build_*_parser` 模式将各功能模块（如 `gateway`, `model`, `auth`）的解析逻辑解耦，并通过依赖注入方式注册到主解析器。
- **业务实现层**：包含大量独立的功能模块文件（如 `gateway.py`, `profiles.py`, `mcp_catalog.py`），分别处理具体的业务逻辑。
- **集成服务层**：`dashboard_auth/` 子包基于 FastAPI 实现了 OAuth2/OIDC 认证路由与中间件；`proxy/` 子包提供了本地 OpenAI 兼容代理服务器，支持 Nous Portal 等上游适配。

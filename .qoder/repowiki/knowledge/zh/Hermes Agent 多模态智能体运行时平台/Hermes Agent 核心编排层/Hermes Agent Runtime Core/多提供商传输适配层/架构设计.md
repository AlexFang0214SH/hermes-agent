- **策略模式实现**：定义 `ProviderTransport` 基类 (`base.py`)，由 `ChatCompletionsTransport`、`ResponsesApiTransport` (Codex) 和 `BedrockTransport` 等具体子类实现，通过 `api_mode` 属性进行路由。
- **统一数据契约**：使用 `NormalizedResponse` 和 `ToolCall` 数据类 (`types.py`) 作为所有提供商响应的标准输出格式，屏蔽底层 API 差异。
- **适配器委托**：复杂的格式转换逻辑（如消息结构映射、工具定义转换）委托给独立的适配器模块（如 `anthropic_adapter.py`, `codex_responses_adapter.py`, `bedrock_adapter.py`），传输层仅负责协调调用与结果封装。
- **自动注册机制**：各传输子类在导入时通过 `register_transport` 自动注册到全局工厂，实现解耦扩展。

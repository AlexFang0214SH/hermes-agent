- **Transport Abstraction**: Uses a `ProviderTransport` interface (in `transports/`) to normalize heterogeneous LLM APIs (OpenAI, Anthropic, Bedrock) into a unified internal model, allowing the core conversation loop to remain provider-agnostic.
- **Concurrency & Isolation**: Manages tool execution via a `ThreadPoolExecutor` with thread-local context propagation (for approvals/callbacks) and interrupt fan-out, ensuring safe parallel dispatch of file/terminal operations.
- **Credential Orchestration**: Implements a persistent `CredentialPool` that aggregates secrets from diverse sources (env vars, OAuth singletons, Bitwarden Secrets Manager) and handles automatic token refresh, failover strategies, and cross-process state synchronization via `auth.json`.
- **Async/Sync Bridging**: Runs an isolated asyncio event loop in a daemon thread to manage long-lived LSP server subprocesses, exposing a synchronous API to the main agent thread for real-time diagnostic feedback during file edits.

- 采用 Store + Patch 模式：所有状态修改必须通过导出的 `patchXxxState` 函数进行，支持传入部分对象或状态更新函数，确保状态变更的可追踪性和原子性。
- 控制器与视图分离：复杂的业务逻辑（如消息分段、推理文本处理、工具轨迹生成）封装在独立的 Controller 类（如 `TurnController`）中，Hooks 仅负责桥接控制器与 React 组件。
- 事件处理器工厂模式：使用 `createGatewayEventHandler` 和 `createSlashHandler` 等工厂函数，通过闭包注入依赖（如 `rpc`, `sys`, `appendMessage`），避免在组件内部维护庞大的回调逻辑。
- 忙时输入策略化：在 `useSubmission.ts` 中根据配置（queue/interrupt/steer）动态处理会话繁忙时的用户输入，提供一致的用户体验。

- **状态管理层**：基于 `nanostores` 实现轻量级全局状态管理，分为 UI 状态 (`uiStore.ts`)、当前轮次状态 (`turnStore.ts`)、覆盖层状态 (`overlayStore.ts`) 和委托状态 (`delegationStore.ts`)。
- **控制器层**：采用集中式控制器模式，`turnController.ts` 管理消息流、推理过程和工具调用轨迹；`useSubmission.ts` 处理提交逻辑（包括插值、队列和忙时策略）；`useInputHandlers.ts` 统一处理键盘和鼠标事件。
- **事件驱动层**：`createGatewayEventHandler.ts` 作为网关 WebSocket 事件的中央分发器，将后端事件映射为 UI 状态更新或转录消息。
- **生命周期层**：`useSessionLifecycle.ts` 封装会话的创建、恢复、激活和关闭逻辑，并与文件系统同步活跃会话状态。
- **入口组件**：`useMainApp.ts` 作为顶层 Hook，组合上述所有模块，协调 React 渲染与底层 Ink 终端库的交互。

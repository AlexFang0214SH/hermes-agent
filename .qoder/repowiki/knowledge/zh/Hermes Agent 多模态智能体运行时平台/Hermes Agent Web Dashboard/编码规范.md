- 所有 API 请求均通过 `lib/api.ts` 中的统一客户端发起，自动处理基础路径前缀（`HERMES_BASE_PATH`）和管理员 Profile 作用域参数（`?profile=`）。
- UI 组件广泛采用 `class-variance-authority` (CVA) 和 `clsx` 结合 `cn` 工具函数来管理条件类名和变体样式。
- 插件系统与主应用通过全局 Window 对象进行通信，插件 bundle 需调用 `window.__HERMES_PLUGINS__.register` 完成组件注册。
- 页面级组件通常放置在 `src/pages` 目录下，并通过 `App.tsx` 中的 `BUILTIN_ROUTES_CORE` 映射表进行路由绑定。

- **技术栈与构建**：采用 React 19 + TypeScript + Vite 4 架构，使用 Tailwind CSS v4 进行样式管理，通过 `@nous-research/ui` 共享设计语言组件。
- **路由与布局**：以 `App.tsx` 为核心布局容器，集成 `react-router-dom` 实现多页面导航；支持侧边栏折叠、移动端响应式适配及深色/浅色主题切换。
- **状态管理**：利用 React Context API 构建全局状态层，包括 `ProfileProvider`（多环境配置切换）、`I18nProvider`（国际化）和 `SystemActionsProvider`（网关重启/更新状态）。
- **插件化架构**：设计了基于 `window.__HERMES_PLUGINS__` 的全局 SDK 注入机制，允许外部脚本动态注册 UI 组件并挂载至预定义的 `PluginSlot`（如侧边栏、页头或特定页面区域），实现了核心功能与扩展功能的解耦。
- **通信层**：封装 `api.ts` 统一处理 RESTful 请求与 WebSocket 连接，内置 Session Token 自动注入、OAuth 票据交换及多 Profile 作用域参数拼接逻辑。

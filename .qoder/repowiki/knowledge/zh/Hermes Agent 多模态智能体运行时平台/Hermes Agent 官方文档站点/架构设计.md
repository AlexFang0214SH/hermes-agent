- **框架核心**: 采用 Docusaurus 3.9 (Classic Preset) 作为静态站点生成器，配置了 Mermaid 图表渲染和本地搜索插件 (@easyops-cn/docusaurus-search-local)。
- **内容架构**: 文档按受众分层为 Getting Started, User Guide (含 Features, Messaging, Skills), Developer Guide, Guides 和 Reference，通过 `sidebars.ts` 定义复杂的嵌套侧边栏结构。
- **国际化策略**: 支持 `en` 和 `zh-Hans` 双语，源文件分别位于 `docs/` 和 `i18n/zh-Hans/` 目录下。
- **动态数据流**: 通过 `scripts/prebuild.mjs` 在构建前执行 Python 脚本 (`extract-skills.py`, `generate-llms-txt.py`)，从源码或远程 API 提取技能元数据并生成 `static/api/skills.json` 等静态资源，供 React 组件 (`src/pages/skills/`) 消费。
- **入口与扩展**: 包含自定义 React 页面（如 Skills Hub）和组件（AutomationBlueprintsCatalog），并通过 `docusaurus.config.ts` 配置了从旧路径到新路径的重定向规则。
